# H5 Gaming World

A beginner-friendly premium dark-themed HTML5 gaming portal.

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in your browser.
3. Search games and try the category filters.

## Files
- `index.html` — page structure
- `style.css` — responsive dark gaming design
- `script.js` — sample game cards, search, and category filters

Note: The Play Now buttons are placeholders. Actual playable games will be added in a later development step.
